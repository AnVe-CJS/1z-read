1z read — 使用说明
================================================

在任意软件里用鼠标选中一段文字，松手后旁边弹出小气泡，点一下就把这段文字
交给 AI 搜索 / 解析。Windows 10 / 11。


一、安装后你得到了什么
------------------------------------------------

  1z read.exe                    助手本体（托盘运行，无窗口）
  卸载程序.exe                   卸载入口（「设置 → 应用」里也能找到 1z read）
  web\                           面板网页源码（要给 WorkBuddy 发布你自己那一份）
  extension\                     浏览器扩展（可选件，见 extension\说明.txt）
  docs\1z read 使用说明.txt      本文件
  docs\1z read 接入说明.txt      首次接入的三步走

  安装位置默认：%LOCALAPPDATA%\Programs\1z read
  运行数据：    %LOCALAPPDATA%\TextLens\（面板网址、本机钥匙、日志）


二、第一次用：先花两分钟接入
------------------------------------------------

工具**不自带**任何公共 AI 额度 —— 每个人用自己的那份，各花各的。
所以第一次启动会弹出「接入你自己的 AI 额度」向导，按里面三步走完即可。

没接入之前，划词是没有反应的，这不是坏了，是故意的。

详细步骤见 docs\1z read 接入说明.txt。


三、日常使用
------------------------------------------------

  1. 在任意软件里用鼠标选中一段文字（Word / PDF / 微信 / 网页 / 代码编辑器都行）
  2. 松开鼠标，约 0.4 秒后文字附近弹出小气泡
  3. 点气泡里的「AI 搜索」或「解析」
  4. 面板窗口自动弹到前面，之后直接在面板里继续追问

  每个选区自动开一个独立会话，历史都留在面板左侧 ☰ 里。


四、托盘图标
------------------------------------------------

  面板点 × 关闭时会问你「后台运行 / 关闭 1z read」，勾「下次不再询问」
  就记住你的选择。后台运行时只在屏幕右下角通知区域留一个小图标：

  · 左键单击：重新打开面板
  · 右键菜单：打开面板 / 接入设置… / 退出


五、开机自启
------------------------------------------------

  安装时勾了「开机自动启动」的话，登录后会自动在后台运行，无窗口。
  想改：右键托盘图标 →「退出」，重新运行安装程序重新勾选即可；
  也可以直接删除启动目录里的 1z read.vbs：
      %APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup


六、环境要求
------------------------------------------------

  · Windows 10 / 11
  · Microsoft Edge WebView2 运行时（Win10 / 11 随 Edge 一起装，绝大多数机器已有）

  面板本身就是一个进程内的 WebView2 窗口，**不需要 Node.js**。
  只有系统里确实缺 WebView2 运行时的机器，助手才会退回「用 Edge/Chrome 开一个
  应用窗口」的兼容模式 —— 那种情况才需要 Node.js 22+ 和 Edge / Chrome。
  安装向导里会自动检测，缺什么会明确提示。


七、隐私与安全（内置，默认开启）
------------------------------------------------

  1. 受保护程序不取词
     密码管理器、网银 / 支付类程序、系统凭据界面（UAC）里，助手不读取任何
     文字：不弹气泡、不取词，日志里连窗口标题都不记。

  2. 剪贴板不留痕
     划词取词需要借一次 Ctrl+C，取完会把原来的剪贴板内容原样还原。

  3. 日志不记内容
     helper.log 只记"取了几字、来自哪个程序"，不记你划的文字本身。

  4. 钥匙只在本机
     面板网页里**不含**钥匙；钥匙只存 %LOCALAPPDATA%\TextLens\cloud.json，
     打开面板时由助手注入。别人拿到你的面板网址也调不动模型。


八、出问题按顺序查
------------------------------------------------

  1. 助手在不在跑？任务管理器里找「1z read.exe」。
     不在就双击桌面图标（或开始菜单里的 1z read）。

  2. 看日志：%LOCALAPPDATA%\TextLens\helper.log
     里面记录了每一次划选、计时、气泡显示、点击、推送。

  3. 划词没反应、面板也打不开 → 大概率是还没接入，右键托盘图标
     选「接入设置…」补上。

  4. 面板提示"请通过 1z read 桌面助手打开" → 说明这个面板不是助手打开的，
     是"额度保护"生效的正常表现，从助手这边打开即可。

  5. 气泡出来了但点了解析没内容：个别软件里 Ctrl+C 不是复制（部分终端、
     游戏），这种地方手动把文字粘到面板里即可。


九、卸载
------------------------------------------------

  方式一：设置 → 应用 → 1z read → 卸载
  方式二：运行安装目录里的「卸载程序.exe」

  卸载会移除：程序本体、桌面与开始菜单快捷方式、开机自启、卸载项。
  本机配置（面板网址与钥匙）默认**保留**，可在卸载窗口里勾选一并删除。


十、重装 / 升级
------------------------------------------------

  直接运行新版的「1z read 安装程序.exe」覆盖安装即可，配置和会话历史都保留。
