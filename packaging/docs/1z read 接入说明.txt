1z read · 接入说明
================================================
（第一次用，或者换一台电脑重新接入，看这份。全程大约两分钟。）


一、先搞懂一件事：为什么要"自己发布一份"
------------------------------------------------

1z read 的面板本身**不带**任何钥匙。钥匙只存在你本机，打开面板时由助手
注入进去。这样设计是为了解决一个很实际的问题：

  云服务的"免密钥"通道，只按**调用来源域名**发放额度，而且是**精确匹配**
  —— 面板的域名和钥匙必须属于**同一个应用**。

由此推出两个结论：

  · 别人拿到你的面板网址也调不动模型（他那边没有钥匙）；
  · 反过来，你想用**自己**的额度，就必须有一份**自己发布**的面板。
    拿别人的域名配自己的钥匙，服务端会直接拒绝。

所以这个工具的用法是：**每个人都发布自己的一份，各花各的额度。**
你不需要为别人的使用买单，别人也不占用你的。

这也是"接入门"的由来：**没接入之前，工具是完全不可用的**（划词没有反应、
面板也不打开）。这不是坏了，是故意的 —— 不然就只能花发布者的额度了。


二、前置条件
------------------------------------------------

  · Windows 10 / 11
  · Microsoft Edge WebView2 运行时（Win10 / 11 一般已自带）
    面板本身是进程内的 WebView2 窗口，不依赖 Node.js；只有缺 WebView2 的机器
    才退回 Edge 兼容模式，那时才需要 Node.js 22+ 和 Edge / Chrome
  · 一个 WorkBuddy 账号（用来发布你自己的那一份）
  · 本机装了 WorkBuddy（用它来做发布，见下一步）


三、三步接入
------------------------------------------------

【第 1 步】发布你自己的一份

  用 WorkBuddy 打开**安装目录**（默认在
  %LOCALAPPDATA%\Programs\1z read，就是有 web\ 子目录的那个目录），
  然后对 AI 说下面这段话：

   ┌──────────────────────────────────────────────────────┐
   │ 请帮我把这个项目发布成我自己的应用，并开通云服务：        │
   │                                                      │
   │ 1. 给这个项目开通云服务环境（如果已经开通过就直接复用）     │
   │ 2. 把 web 目录发布成站点，入口是 index.html             │
   │ 3. 完成后把这三项告诉我：                              │
   │    · publishableKey（wbpk_ 开头）                     │
   │    · resourceId（wbcs_ 开头）                         │
   │    · 发布后的网址                                     │
   │                                                      │
   │ 注意：网页源码里不要写入任何钥匙，钥匙我会存在本机。       │
   └──────────────────────────────────────────────────────┘

  它会给你三项：钥匙（wbpk_…）、资源 ID（wbcs_…）和网址。


【第 2 步】把这三项填进本机

  右键托盘里的 1z read 图标 →「接入设置…」，弹出向导：

  · 还没有 WorkBuddy 账号 → 点「去登录 / 注册」打开登录页（页面上有注册入口）
  · 点「复制提示词」，把那段话直接粘给 WorkBuddy，省得自己敲
  · 把第 1 步拿到的三项填进去 →「保存并启用」

  面板网址是必填项（必须以 https:// 开头），resourceId 可以留空。


【第 3 步】开始用

  任意软件里选中一段文字 → 松手 → 点旁边的小气泡。

  面板没打开过的话，助手会自己打开；之后划词会不断往同一个面板里送。


四、怎么确认接好了
------------------------------------------------

  · 划词点气泡后，面板能正常回答 → 成了。
  · 面板右上角模型下拉框显示"未连接"，或提示"请通过 1z read 桌面助手
    打开" → 钥匙没接上，按下节排查。
  · 日志在 %LOCALAPPDATA%\TextLens\helper.log，启动时会打印"面板地址"
    和"cloud.json 是否就绪"，对着看最直接。


五、出问题按顺序查
------------------------------------------------

  1. 助手在不在跑？任务管理器里找「1z read.exe」。不在就双击桌面图标。

  2. cloud.json 存在吗？在 %LOCALAPPDATA%\TextLens\ 下。
     不在就右键托盘图标 →「接入设置…」重填一次。

  3. 面板能打开但一发消息就报错（鉴权类）：多半是"域名和钥匙不是同一个
     应用"。回头确认第 1 步的网址和钥匙确实来自同一次发布。

  4. 想换域名 / 重新发布：重新发布后，用「接入设置…」把新网址填一遍。


六、关于安全
------------------------------------------------

  · cloud.json 里是钥匙，属于**本机专用件**：不要提交到公开仓库。
  · 钥匙泄漏的最坏后果是"你的额度被消耗"，不是账号被入侵 —— 网页侧不含
    钥匙，别人拿到网址也抄不到、发不出。
  · 换电脑：把 cloud.json 拷到新机器的同一位置，再「接入设置…」确认一遍
    更稳妥。


七、面向二次分发（把工具给别人用）
------------------------------------------------

  直接把「1z read 安装程序.exe」发给对方即可，对方自己走一遍上面的三步。
  注意不要连同你自己的 cloud.json 一起发出去 —— 那是你的额度。
