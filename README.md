# 1z read · 划词即可问 AI

Windows 划词助手：在**任意软件**里选中文字 → 悬浮气泡 → 就地唤起 AI 面板，
自动把选区送进对话并继续追问。无需登录、无需自己申请模型 API ——
额度走你在 WorkBuddy 里发布的那一份云服务。

![预览](desktop/app-preview.png)

## 它是怎么工作的

1. 任意程序里划选文字（记事本、PDF、浏览器、微信……都行）；
2. 松开鼠标稍等，选区旁弹出小气泡；
3. 点「AI 搜索 / 解析」→ 面板窗口自动弹出，选区已在输入框里；
4. 之后就是一个普通的多轮对话面板，历史会话留在左侧 ☰。

## 亮点

- **进程内 WebView2 面板**：独立无边框窗口（圆角、可拖动、可最小化/最大化），
  不是浏览器标签页，无浏览器痕迹；没有 WebView2 的机器自动退回 Edge 应用窗口兜底。
- **钥匙不落地**：面板网页本身不含任何云服务钥匙。钥匙只存本机
  `%LOCALAPPDATA%\TextLens\cloud.json`，打开面板时由桌面助手注入。
  网页源码就算被人拿到，也只是个空壳。
- **隐私默认开启**：密码管理器、网银等受保护程序不取词；取词借用的
  Ctrl+C 用完即还原剪贴板；日志只记「取了几字、来自哪个程序」，不记内容。
- **各花各的额度**：面板网址与钥匙必须属于同一个应用，所以每个人发布
  自己的一份面板、填自己的钥匙 —— 谁也不蹭谁。

## 安装

### 方式一：安装包（推荐）

从 [Releases](../../releases) 下载 `1z read 安装程序.exe`（单文件，内嵌主程序、
面板网页、浏览器扩展与卸载程序），双击安装即可。安装向导会自动检测
WebView2 运行时（Win10/11 一般自带）。

### 方式二：从源码运行

需要 Python 3.13+（带 tkinter）：

```bat
pip install pywebview pythonnet
pythonw desktop\lens.py
```

首次启动会弹出「接入向导」，按提示填入你自己的面板网址与钥匙。

## 接入你自己的额度（三步）

工具本身不自带公共 AI 额度 —— 未接入前划词不会有响应，这是故意的。

1. **发布你自己的一份面板**：在 [WorkBuddy](https://www.workbuddy.cn/) 里把
   本仓库的 `web/` 目录发布为一个网站，得到你的面板网址；
2. **拿到钥匙**：右键托盘图标 →「接入设置」，跟着向导走一遍（或
   `python lens.py --setup`），填入面板网址、`publishableKey`（`wbpk_` 开头）
   与 `resourceId`（可留空）；
3. 完成。钥匙落在本机 `cloud.json`，之后每次打开面板由助手自动注入。

详细图文见 [`packaging/docs/1z read 接入说明.txt`](packaging/docs/1z%20read%20接入说明.txt)。

## 浏览器扩展（可选）

想在普通浏览器标签页里划词（而不是唤起桌面面板）的话，加载 `extension/`：

1. 先把 `extension/app-unlock.js` 里的钥匙填成你自己的（**仓库里的版本故意
   留空**，见文件内说明），并把 `manifest.json` / `content.js` 的域名换成
   你自己发布的面板网址；
2. 浏览器打开 `chrome://extensions`（Edge 一样）→ 开启「开发者模式」→
   「加载已解压的扩展程序」→ 选中 `extension/` 目录。

## 自己打包

```bat
pip install pyinstaller
python packaging/build_release.py
```

产物在 `release/`：单文件安装程序 + 同名 zip。发布脚本会自动把扩展里的
钥匙清空、域名换成占位符，避免把你的额度打包送人。

## 目录结构

```
desktop/    桌面助手主程序（lens.py）+ WebView2 面板宿主（panelwin.py）
web/        面板网页（每人发布自己的一份；不含钥匙）
extension/  浏览器扩展（可选件；仓库版不含钥匙）
packaging/  打包脚本（安装程序 / 卸载程序 / 发布清理）+ 说明文档
```

## 隐私与安全

- 面板与云服务的免密钥通道按「调用来源域名 + 钥匙」双重匹配，二者必须
  属于同一应用 —— 拿到网址的人调不动模型，拿到钥匙的人离了对应域名也不行；
- 受保护程序（密码管理器 / 网银 / UAC）不取词；
- 剪贴板取词后立即还原；
- 日志不记录划词内容。
